# v0.7.2-local.1

DashBeam 定制 fork 的兼容升级：完整合入官方 v0.7.2 和 main `c5de165`，
保留文字/剪贴板、macOS 菜单栏、可选闪传、Finder Share 与接收完成复制功能。
冻结产品源码：`07d999b479e25657e6374e413210a0c086c0b853`。
产品版本 `0.7.2`，Mac / Android build `70201`。

## 本轮改进

- 新增默认关闭、逐次选择的“优先快速发送（实验）”：单个普通文件不超过 8 GiB，
  在支持该能力的已配对定制端之间复用常驻设备节点，直接读取已有源文件并流式接收，
  不先完整扫描/hash，也不把源文件另存一份。传输中的增量完整性校验仍保留。
- 邀请之前，通过当前 CONTROL 连接有界确认对方能力；官方、旧版或未知端先选择普通
  BlobTicket 路径，只准备/邀请一次。能力不写入持久配对记录，重连后重新检查。
- Invite 开始写入后不自动重发，避免重复邀请；取消与邀请写入共享门控。
  legacy 回退后即使投递失败也保留真实票据，允许用户明确选择下一步。
- 官方网络依赖同步至 Iroh 1.3.0、iroh-blobs 0.103.1、rustls 0.23.45；
  保留本地导出路径、文字信任校验和取消/并发保护。
- 构建产物名称随产品版本生成；中英文 README 与官方同步流程更新，历史下载链接不改。

## 安装与兼容边界

- macOS：Apple Silicon ARM64 ZIP；本地签名，未 Apple 公证。升级时只保留一个
  `/Applications/DashBeam.app`，原有身份、配对和设置应保留。
- Android：ARM64，最低 Android 10 / API 29，保持既有定制包
  `com.dashbeam.android.local` 和定制签名，可升级相同包名/签名的旧定制版。
  无法覆盖使用不同包名或签名的官方 APK；不要为此卸载有配置的官方端。
- Windows：x64 NSIS 安装器与便携 ZIP；本轮构建未代码签名。
- Linux：amd64 deb；实际桌面/托盘行为仍需对应环境验收。
- 普通文件保持官方协议；文字向未修改的官方客户端降级为普通 `.txt` 文件，
  不要求其显示定制文字面板或自动写剪贴板。
- 多文件、目录、文字、未配对/Nearby、广播和 Flash Drop 继续走兼容路径。
  Android SAF 选择器的首次本地暂存仍存在；快速模式没有断点续传，源文件应保持不变。
- 未加入服务端磁盘 spool，未修改生产中继。历史网络模拟不等于当前 GUI 全链路性能保证，
  不承诺任意网络三秒内开始传输。
